# Historical LoRA adapters

This experiment recovered and evaluated older adapters and included an emergency
retraining script. Its Python entrypoints are archived in
`.legacy/lora_experiments/series_00_legacy_adapters/`. Adapter files and reports
remain in ignored local archives. The [8k classifier experiment](../../classifiers/README.md)
is the current LoRA goal; the [baseline retraining workflow](../../baselines/series_01_classifiers/README.md)
remains available for historical reproduction.
