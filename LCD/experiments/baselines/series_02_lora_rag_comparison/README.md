# Historical LoRA/RAG comparison

This series evaluates explicitly selected historical three-class LoRA adapters with a local RAG bundle and compiles saved LoRA/RAG results. It retains old comparisons as evidence; its evaluator and compiler remain available for local reproduction. It is not part of the current dataset-creation or 8k LoRA work. Entry points and input requirements are in the [baseline instructions](../instructions.md).
